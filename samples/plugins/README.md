# Plugins

The plugins, Messenger among them, live in the [LlamaTree-Plugins](https://github.com/LlamachantTechnology/LlamaTree-Plugins) repository: one folder per plugin, each with a release to download, the manifest schema, the checks a plugin must pass and how one is written and released. See [Plugins](../../README.md#plugins) in the README for what a plugin can do.
