# Keyboard shortcuts

The keys and clicks that get you around LlamaTree. On macOS, <kbd>⌘</kbd> does what <kbd>Ctrl</kbd> does here (<kbd>⌘</kbd>+<kbd>1</kbd>…<kbd>9</kbd>, <kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd>, <kbd>⌘</kbd>+<kbd>W</kbd> and so on), and the Ctrl keys go to the terminal as themselves.

## Sessions

| Action | Shortcut |
|---|---|
| Open a session full size | <kbd>Ctrl</kbd>+<kbd>1</kbd> … <kbd>Ctrl</kbd>+<kbd>9</kbd>, or click its tile or tab |
| Back to all sessions | <kbd>Shift</kbd>+<kbd>Esc</kbd>, click the open session's tab again, the collapse button in the tile header, or the mouse Back button |
| Next / previous session | <kbd>Ctrl</kbd>+<kbd>Tab</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> |
| New session | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> |
| Close a session | The × on its tab, or middle-click the tab |
| Project view | Click the project's name at the start of its tab group (again to go back) |
| Show only one project | <kbd>Ctrl</kbd>+click its name in the Projects row, or right-click it › *Show only this project* |

## Terminal

| Action | Shortcut |
|---|---|
| Go to the terminal | <kbd>Esc</kbd> (Claude Code also uses it to interrupt) |
| Newline in the prompt | <kbd>Shift</kbd>+<kbd>Enter</kbd> |
| Copy / paste | <kbd>Ctrl</kbd>+<kbd>C</kbd> with a selection / <kbd>Ctrl</kbd>+<kbd>V</kbd>, or right-click. Files copied in Explorer paste as their paths |
| Paste a screenshot | <kbd>Ctrl</kbd>+<kbd>V</kbd> with an image on the clipboard: it pastes the path of a PNG saved from it, which Claude Code and Codex attach |
| Font size | <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> / <kbd>Ctrl</kbd>+<kbd>0</kbd> |
| Terminals solid or see-through | The small slider in the terminal's bottom-right corner (on the open terminal; on a tile while the pointer is over it), or the palette button › *Terminal background › Change…*; remembered for the theme you're on |
| Open a file or folder named in the output | Click its path (underlined on hover once it's found to exist); right-click for *Open containing folder* and *Copy path*. Files open to view or edit, never run |
| Read back through the conversation | Hover the ticks at the right edge; click one (or right-click › *Show conversation*) to open the Conversation tab there |

## Git and diffs

| Action | Shortcut |
|---|---|
| Toggle the side panel | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> (with nothing in it, opens its options) |
| Preview a file's diff | Click it (italic tab, reused); double-click to keep it open |
| Terminal ↔ diff tabs | <kbd>Ctrl</kbd>+<kbd>PgUp</kbd> / <kbd>Ctrl</kbd>+<kbd>PgDn</kbd>, click the Terminal tab, or <kbd>Shift</kbd>+<kbd>Esc</kbd> from a diff |
| Next / previous change | <kbd>Alt</kbd>+<kbd>↓</kbd> / <kbd>Alt</kbd>+<kbd>↑</kbd> |
| Close a diff tab | <kbd>Ctrl</kbd>+<kbd>W</kbd> or <kbd>Ctrl</kbd>+<kbd>F4</kbd>, middle-click, or the tab's × (in the terminal <kbd>Ctrl</kbd>+<kbd>W</kbd> stays Claude's delete-word) |
| Put a tab beside the terminal | Drag it towards an edge of the terminal area, or right-click it and pick a side. While split, <kbd>Shift</kbd>+<kbd>Esc</kbd> goes back to the terminal and leaves the tab there, and <kbd>Ctrl</kbd>+<kbd>W</kbd> closes the tab only while you're in it |
| Undo a suggested commit message | <kbd>Ctrl</kbd>+<kbd>Z</kbd> in the message box brings back what was there before **Suggest** |
